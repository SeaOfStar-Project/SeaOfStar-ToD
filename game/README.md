# game

Put your own disc dump here.

Supported inputs:

| Format | Notes |
|---|---|
| `.iso` | Raw disc image |
| `.rvz` | Dolphin's compressed format; `nodtool` extracts it directly |
| `.wbfs` | USB-loader format; `wit` or `nodtool` handles it |

The file is gitignored. Do not commit, share, or upload it.

The verified USA title for this project is `SO3EE9` (`Rune Factory: Tides of Destiny`).
If you dump a PAL or Japanese disc, check the six-character ID in the disc header and update
`config/game.json`.

Nothing in this repository downloads or contains game data. You must own the game.
